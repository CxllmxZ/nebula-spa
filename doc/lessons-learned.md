## 🔴🔴🔴 บทเรียน #1 — โปรเจกต์หน้า: แยก Frontend กับ API ตั้งแต่วันแรก 🔴🔴🔴

> ### ⛔ อย่าใช้ Next.js ทั้งก้อน (หน้าเว็บ + API รวมกัน) บน Cloudflare Workers แพ็กเกจฟรีอีก
> ### ✅ โปรเจกต์หน้า: Frontend = ไฟล์ static · API = Worker เล็ก (เช่น Hono + Drizzle)

**บันทึกเมื่อ:** Day 39 (26 ต.ค. 2026)

### เกิดอะไรขึ้น
- เจอ **Error 1102 (Worker exceeded resource limits)** ซ้ำหลายครั้ง: หน้าแรก, หน้าจอง, cron สรุปตอนเช้า
- Day 39 เว็บล่มทั้งเว็บหลายนาที **ทั้งที่ยังไม่ได้ deploy โค้ดใหม่** → ต้นเหตุไม่ใช่โค้ด แต่เป็นโควตาของแพ็กเกจ
- แพ็กเกจฟรีให้ CPU **10ms ต่อ 1 คำขอ** แต่ Next.js บน Workers ใช้ประมาณ 15–40ms (ค่ากลางที่เห็น 21ms)

### ต้นเหตุจริง (ไม่ใช่ "รัน front กับ api พร้อมกัน")
1. **Next.js หนักในตัวเอง** — ทุกคำขอ แม้แต่ API ตัวเล็ก ต้องผ่าน routing/middleware ของ Next ก่อน
2. **ก้อนโค้ดใหญ่ + cold start** — server ที่หลับอยู่ต้องโหลด Next ทั้งก้อน → เกินโควตา → โดนตัด → เริ่มใหม่ → เกินอีก (วนได้)
3. cron ช่วงเช้าไม่มีคนใช้ = cold start ทุกรอบ → ยอด CPU แหลมในกราฟ

### ทำไมแยกแล้วดีกว่า
| | Next.js รวม (ตอนนี้) | แยก Frontend / API |
|---|---|---|
| หน้าเว็บ | รันโค้ดทุกครั้ง กิน CPU | ไฟล์ static — **ไม่ใช้ CPU ของ Worker เลย** |
| API ต่อคำขอ | ~15–40ms | ~1–5ms (Hono + Drizzle) — ประมาณการ |
| แพ็กเกจฟรีพอไหม | ❌ ไม่พอ | ✅ น่าจะพอ |
| ที่ทำงาน | — | ใช้เทคนิคนี้อยู่แล้ว |

### ทำไมไม่ refactor โปรเจกต์นี้
- ประเมิน 30–50 ชม. (3–5 สัปดาห์ที่จังหวะ 1–2 ชม./วัน) + ต้องเทสใหม่ทุกฟีเจอร์ตั้งแต่ Day 31–39
- เลื่อนวันขาย = เลื่อนการรู้ผลจากลูกค้าจริง
- **ทางแก้ของโปรเจกต์นี้: อัป Cloudflare Workers Paid $5/เดือน (ต่อบัญชี)** → CPU 30 วินาที/คำขอ
- ถ้าคนซื้อติดเรื่องค่า $5/เดือน = หลักฐานว่าควรทำ v2 แบบแยก

### Checklist โปรเจกต์หน้า (ตัดสินใจก่อนเขียนโค้ดบรรทัดแรก)
- [ ] Frontend: static (เช่น Vite + React หรือ Next `output: "export"`) → Cloudflare static assets
- [ ] API: Worker แยก (Hono + Drizzle + D1) — auth / cron / webhook อยู่ฝั่งนี้
- [ ] ออกแบบ auth ข้ามกัน (cookie / domain เดียวกันผ่าน routes) ตั้งแต่แรก
- [ ] วัด CPU ต่อคำขอใน Cloudflare Logs ตั้งแต่ deploy แรก ไม่ใช่รอเจอ 1102
- [ ] cron เรียกโค้ดตรง ไม่ยิงผ่าน framework

## ข้อมูลอ้างอิง Cloudflare Workers (เช็คเมื่อ 26 ต.ค. 2026)
| | Free | Paid ($5/เดือน ต่อบัญชี) |
|---|---|---|
| CPU ต่อ 1 คำขอ | 10ms | 30 วินาที (ตั้งได้ถึง 5 นาที) |
| CPU ต่อ cron | 10ms | 30 วินาที |
| คำขอ/วัน | 100,000 ต่อบัญชี (เกิน = 1027) | 10 ล้าน/เดือน รวมในราคา |
| Worker ต่อบัญชี | 100 | 500 |
| Cron ต่อบัญชี | 5 | 250 |

- CPU นับเฉพาะเวลาที่โค้ดรัน — เวลารอ D1 / LINE ไม่นับ
- เกินบ้างเป็นครั้งคราว Cloudflare ยอม ถ้าเกินต่อเนื่องจะตัด (1102)
- ที่มา: developers.cloudflare.com/workers/platform/limits และ /pricing
